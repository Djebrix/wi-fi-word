One word describing my Wi-Fi: **ghosting** — it vanishes mid-call without a word of explanation, then reappears as if nothing happened. See the competition at https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72.

## Run

```sh
python3 main.py
```

This writes the one word to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
